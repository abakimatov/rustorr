# Полная совместимость и функциональный паритет в первой версии

Rustorr должен быть полностью совместим с TorrServer и уже в первой версии продукта иметь функциональный паритет с ним. Пользователь выбрал это требование вместо предложенного выпуска с поддержкой только основных сценариев воспроизведения, сохранив пожелание получить результат как можно раньше; следовательно, сокращённый набор функций нельзя считать завершённой первой версией.

Эталон фиксируется на текущем стабильном релизе TorrServer [MatriX.145](https://github.com/YouROK/TorrServer/releases/tag/MatriX.145), commit `2c7fa43b9ac64a9eda27314c0b6791518497f188`. Новые изменения upstream не расширяют объём первой версии автоматически.

Совместимость означает работу существующих клиентов без изменений. Перенос старой папки данных не является обязательным условием замены; новый веб-интерфейс допустим. Первая версия предназначена только для Linux; подробные критерии проверки контрактов ещё формируются по эталону.

Промежуточные исследовательские сборки с ограниченным набором функций разрешены как этап будущей разработки, но не считаются первой версией продукта. Продолжается проектное интервью; переход к реализации ещё не утверждён.

Первая версия рассчитана на начальную нагрузку 1–3 устройства. Подтверждение 100 одновременных просмотров выделено в следующий этап, сохраняя полный функциональный паритет как условие первой версии.

Эффективность принимается измерительно: сначала снимается baseline MatriX.145 в контролируемых сценариях, затем задаются численные цели Rustorr. До этих замеров нельзя объявлять конкретный процент ускорения или окончательно выбирать BitTorrent-движок; промежуточные прототипы разрешены для снятия технических рисков.

Первая версия ориентирована на Linux `x86_64` и `aarch64` и поставляется самостоятельным бинарником и Docker-образом. До реализации должен появиться отдельный поэтапный план; реализация начнётся только после его последующего согласования.

Rustorr должен поддерживать встроенный TLS и работу за reverse proxy/VPN, сохраняя модель авторизации TorrServer. Состояние хранится в новом внутреннем формате; импорт базы TorrServer вынесен за пределы первой версии.
