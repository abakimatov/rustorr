# Rustorr 1.0.0-rc.1

Первый release candidate: замена TorrServer MatriX.145 на Rust с тем же
HTTP API и новым веб-интерфейсом.

## Что внутри

- **Совместимость с клиентами TorrServer.** API торрентов, настроек,
  «просмотрено», кэша и WAF; потоковое воспроизведение с диапазонами;
  плейлисты M3U; DLNA и Bonjour; поиск Rutor и Torznab; MSX; WebDAV и
  FUSE; ffprobe; HLS через GStreamer (вариант образа). Проверено
  контрактными корпусами против закреплённого MatriX.145.
- **Веб-интерфейс** (русский и английский): список и добавление
  торрентов, плеер в браузере — напрямую и через HLS с выбором звука и
  субтитров, продолжение просмотра, поиск, настройки, карта кэша.
- **Развёртывание** через Docker по SSH (`tools/deploy.sh`): установка,
  обновление с бэкапом и автоматическим откатом, бэкап и восстановление,
  свой сертификат, смена пароля. Встроенный HTTPS как у MatriX,
  метрики Prometheus, флаги MatriX и переменные `TS_*` его образа.

## Быстрее MatriX.145

Стенд R1 (локальный трекер и сидер, одинаковые условия), p95:

| | Rustorr | MatriX.145 |
|---|---|---|
| холодный старт `.torrent` | 9,4 с | 10,9–12,8 с |
| magnet: от добавления до сида | 1,0 с | 5,1–6,1 с |
| тёплый старт | 5 мс | 5,0 с (7 мс в свежем прогоне) |
| перемотка в загруженное | 0,95 с | 4,5 с |
| перемотка в незагруженное | 0,09 с | 4,5–8,0 с |
| непрерывно, 1 зритель | 58 мс, 0 остановок | 4,0 с, 28 остановок |
| потери 1 % и 80 мс (80 запросов) | 1,03 с | 1,28 с |

## Ограничения

- Сетевые поля настроек BitTorrent (лимиты скорости, порт пиров,
  `DisableUpload`, шифрование, отключение DHT/PEX/uTP и др.) хранятся, но
  не применяются: сетью движка управляют параметры запуска. Настройки
  отмечают их; на VPS с тарифом за трафик это важно.
- Прокси BitTorrent — только `socks5://`, режимы `peers` и `full`.
- Данные TorrServer (`config.db`) не переносятся.
- Telegram-бот и MCP не входят в эту версию.
- Бинарник — Linux `x86_64` и `aarch64` (glibc 2.36+); вариант с
  GStreamer — только образ Docker.

## Обновление

Первая версия: переход с TorrServer — `docs/deploy.md`, раздел «Замена
TorrServer». Между версиями Rustorr — `tools/deploy.sh <host> deploy`
