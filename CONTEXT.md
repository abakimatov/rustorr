# Rustorr

Торрент-стриминговый сервер на Rust, задуманный как полностью совместимая функциональная замена TorrServer.

## Язык

**TorrServer**:
Исходный проект, относительно зафиксированной версии которого определяются совместимость и функциональные возможности Rustorr.
_Avoid_: Rustorr, новый сервер

**Функциональный паритет с TorrServer**:
Наличие в Rustorr всех возможностей согласованного эталона TorrServer; это требование к первой версии продукта.
_Avoid_: только основные функции, минимальный стриминг

**Совместимость с TorrServer**:
Сохранение внешних контрактов TorrServer, необходимое для работы существующих клиентов без изменений. Совпадение внешнего вида веб-интерфейса и перенос старой папки данных не являются обязательными условиями такой замены.
_Avoid_: только сходство функций

**Одновременный просмотр**:
Активное воспроизведение выбранного торрент-файла одним зрителем в данный момент. Число просмотров отличается от числа подключённых устройств и HTTP-соединений.
_Avoid_: подключение, зарегистрированное устройство

**Прямой просмотр**:
Воспроизведение исходного медиафайла через сервер без перекодирования аудио и видео на сервере.
_Avoid_: транскодирование

**Baseline**:
Контролируемый набор измерений зафиксированного TorrServer, с которым сравниваются Rustorr и выбранный BitTorrent-движок.
_Avoid_: замер на случайном VPS, субъективное сравнение

**Handoff**:
Структурированная запись состояния этапа разработки, позволяющая новой сессии продолжить работу без восстановления контекста из переписки.
_Avoid_: краткий статус
